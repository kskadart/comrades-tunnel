# it knows what "correct" looks like for the personal VPN's route count
# (see check 2 in that script's own header comment):

# `exclude` быстрее `forward`». A mismatch here makes bin/split-health.sh
# misreport check 2 (it will compare the live route count against the
# wrong expectation).
